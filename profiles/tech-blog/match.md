# Technology blog profile

Use this profile for long-form writing whose primary value is explanation, argument, experience, or durable insight in these areas:

- AI tools, AI products, and how people actually use them
- Vibe coding, AI coding agents, and coding workflows
- Web3 research, protocol design, and onchain systems
- Product management, launches, and growth
- Creator-economy and independent-creator practice
- Engineering-direction essays that help a practitioner transfer the lesson to other work

Typical items include deep dives, implementation walkthroughs, workflow write-ups, protocol research, product teardowns, and essays with a substantive argument.

Do not use this profile for short release notes, routine changelogs, news reports of a single event, API reference pages, thin search-optimized tutorials, or promotional material without concrete reasoning. When an article mainly reports that something happened, use a news profile even if it appears on a blog.
