# 评估目标

评估一条信息是否值得关注自媒体、独立创作、内容增长和 AI 创作工具的读者在未来 24–72 小时内跟进，并有机会转化为准确、有判断力、可执行的选题或方法。

# 评分标准

- **9–10：必须跟进。** 创作平台、分发渠道或主流 AI 创作/写作工具发生实质变化；或有可靠证据的增长/变现方法，会明显影响创作者怎么做内容。
- **7–8：值得写。** 有明确的新事实、可解释的意义或可复核的工作流变化，能形成具体而不夸张的选题。
- **5–6：可作素材。** 有一定新意，但影响范围有限、细节不足，或需要与其他材料合并后才值得输出。
- **3–4：低优先级。** 常规更新、重复报道、宣传性强，或对创作者的实际影响不清楚。
- **0–2：噪音。** 传闻、夸大标题、无法证实的说法，或与自媒体、内容增长、创作工具无关。

# 评估要求

优先看原始公告、创作者第一手复盘或可靠报道。区分已发布事实、演示、预告、公司主张和第三方判断。不要把热度当成重要性，也不要因知名公司而自动加分。给出 3–5 个具体主题标签，例如 `creator`、`ai-tools` 或 `product`。
